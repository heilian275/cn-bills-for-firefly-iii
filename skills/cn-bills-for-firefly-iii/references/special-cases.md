# 特殊形态

这些形态在支付宝和微信账单里都会出现。分类之前先看这里，再决定每笔的 type、账户和目标。下面提到的「支付宝第 N 条」「微信第 N 条」都在 `references/bill-formats.md` 里。

- 无效交易：¥0 的行、状态为「交易关闭」的行，都没有资金流。
- 退款对：靠客观字段关联。支付宝看订单号的派生关系（见支付宝第 6 条），微信看金额一致、同一天、原单状态「已全额退款」（见微信第 2 条）。原单和退款金额相抵。
- 复合支付：见支付宝第 5 条。
- 疑似自充值、提现或还款：收/支是「不计收支」，交易分类类似「账户存取」，商品说明类似「充值」，并且「对方账号」和账单里能看到的用户本人号码一致。可以拿话费充值、其他平台绑定的号码交叉验证。这类多半是用户给自己的某个支付账户充值。「收/付款方式」显示的可能是去向而不是来源，来源账户在账单里不体现。
- 平台的「交易分类」是平台口径（餐饮美食、日用百货、商业服务等），用户的分类是用户口径，两者经常对不上。比如平台「美容美发」下的商品，实际可能是日用护肤。导入时平台分类会作为 tag 附在交易上。
